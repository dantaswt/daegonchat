# Daegon Ops

**Daegon Ops** is a responsive operations workspace prototype built to demonstrate how CRM, tasks, finance and customer support can live inside one coherent product.

## Why this project exists

The project connects front-end development with real operational experience. Instead of being a generic dashboard mockup, it models workflows that are common in administrative, commercial and support teams:

- customer and opportunity tracking;
- task prioritization;
- finance overview and upcoming payments;
- support tickets and SLA indicators;
- global search and quick actions;
- CSV export;
- local persistence using `localStorage`;
- responsive desktop/mobile layout;
- light/dark theme.

## Features

### Overview
Operational health, projected revenue, active clients, open tasks, SLA, CRM pipeline, monthly revenue and activity feed.

### CRM
Client list, status filters, opportunity creation and CSV export.

### Tasks
Task creation, status filters, completion tracking and persistent state.

### Finance
Projected balance, receivables, payables, cash-flow visualization and upcoming due dates.

### Support
Ticket overview with priority, elapsed time, SLA and satisfaction metrics.

### Productivity
- `Ctrl + K` global command palette
- quick actions
- notifications panel
- persistent theme
- responsive mobile navigation

## Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage
- Responsive UI / UX

## Demo data

All company, client, finance and support data inside the application is fictional and exists only to demonstrate the product experience.

## Run locally

Open `index.html` directly or serve the repository with any static HTTP server.
