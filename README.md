# Daegon Chat

Daegon Chat is a front-end CRM and customer-service workspace focused on **WhatsApp conversations, bot-assisted service, contacts, sales pipeline, automations and support analytics**.

The product concept is informed by real administrative experience using a CRM with WhatsApp and bot workflows. It is not a copy of Hust Chat or any third-party product; the interface, naming and flows are original.

## Features

- Shared inbox for customer conversations
- WhatsApp-oriented contact history
- Bot / human handoff
- Contact CRM with status and tags
- Sales / service pipeline
- Automation cards and workflow concepts
- Bot builder concept
- Analytics for volume, response time, bot resolution and CSAT
- Global search with Ctrl+K
- Light / dark mode
- Local persistence with localStorage
- Responsive layout

## Stack
HTML, CSS, JavaScript, LocalStorage.
